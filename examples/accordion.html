Effects through .slideToggle and .slideUp.

Why a separate package?

So an app can npm install @itslil/jquery without the LilScript compiler. The compiled JavaScript is the dependency.

Is it smaller than official min?

Not yet. The current compiler-selected artifact is larger than jquery.min.js on Brotli. The site table is the current snapshot, not a size claim.

What still matches?

Behavior of the 3.7.1 public API used by these apps: selectors, events, attributes, deferred, and effects.
