Reusable package artifacts, not a closed-world app. Official lanes are the published jquery.js and jquery.min.js. @itslil/jquery is the LilScript compiler-selected ESM.

Lane Raw gzip-9 Brotli-11 vs original ESM + Terser

Why official min still wins. jQuery is a public-name, string-key, host-heavy library, and a drop-in has to keep every name a page already calls. That ABI is measured below, not assumed. The compiler-selected artifact is the published one; downstream Terser of that artifact is a diagnostic only and is not what npm installs.

What is left to rename

Everything but
the API.

Identifiers are mangled whole-program. Property names are the ABI: a drop-in may only rename what it invented itself. npm run check:names checks every name in the shipped artifact against the pinned jquery@3.7.1 package and fails the build if one the port invented survived.
